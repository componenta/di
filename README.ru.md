# Componenta DI

[Английская версия](README.md)

Контейнер внедрения зависимостей для PHP 8.4+, соответствующий стандарту [PSR-11](https://www.php-fig.org/psr/psr-11/).

Поддерживает автоматическое разрешение зависимостей, явные определения служб и фабрик, псевдонимы, обработчики результатов, атрибуты PHP, вызов функций и методов с внедрением зависимостей, обработку запросов PSR-7 и отложенное создание объектов.

## Установка

```bash
composer require componenta/di
```

Для записи нативных замыканий и ссылок на функции непосредственно в аргументах атрибутов требуется PHP 8.5. Остальные возможности доступны начиная с PHP 8.4.

# Architecture plans

[Русская версия](README.ru.md)

The [fourth deep audit](../audit/2026-11-15-di6-full-reaudit-round4.md) found a lifecycle defect for native Lazy/Proxy targets without backed instance properties. **D1/A was accepted on November 16, 2026 and is implemented in [`299ee93`](https://github.com/componenta/di/commit/299ee93f6be6d91e3a4fc1372389f1fff953d61b).** The [implemented plan](propertyless-lazy-lifecycle.md) defines rejection before object allocation in the default native adapter. The [November 16 fix report](../audit/2026-11-16-propertyless-lazy-fix.md) records the completed implementation scope and validation status. The historical audit retains the defect and decision status at the time of that review.

The [November 15 repeated review](../audit/2026-11-15-di6-repeat-review.md) records two additional consistency corrections, behavior-test proof and complete source coverage after the [preceding full-library review](../audit/2026-11-14-di6-full-library-recheck.md). These fixes preserve the selected architecture. The correction in the [platform specification](php85-callbacks.md#8-php-version-and-release-compatibility) limits E1 to affected native expression forms and removes the earlier whole-release gate.

Implementation was authorized on November 14, 2026, and is isolated on `refactor/di6-definitions-callbacks`, based on the compatible v5.0.6 release commit. Specifications define the contracts; the [implementation report](../audit/2026-11-14-di6-refactoring.md) records what is implemented, tested and still gated. DI 6 is not released.

The previously accepted refactoring was implemented against these contracts; the completed propertyless-lazy repair has its own D1/A verification record. The [completion recheck](../audit/2026-11-14-di6-refactoring.md#completion-recheck) covers three full passes on each local stable runtime, the release-candidate runtime, isolated consumer installations and extension migration. The library retains PHP `^8.4`; E1 limits only affected native-form support and does not delay the library release. The conditional B2 and possible 6.1 DTO work are separate future scopes.

# Componenta DI v5.0.7

[Русская версия](https://github.com/componenta/di/blob/v5.0.7/docs/releases/v5.0.7.ru.md)

This patch fixes dependency resolution and lazy object creation on the DI 5 branch. It supports PHP `^8.4` and the public PHP API of `v5.0.6`.

- Factory, delegator and prepared callable resolution retain the selected receiver and method across autoloading. The lazy request factory caches a validated service and can retry a failed lookup.
- Normalizing configuration and resolving arguments preserve array keys, append indexes and application object identities. Changes to caller-owned reference slots no longer change previously accepted configuration.
- Attribute composition rechecks declarations revealed by autoloading. Custom reflectors keep their metadata separate from cached native reflection plans.
- Property injection uses the declaring scope for inherited private setters. Getters can provide a value before their backing property is initialized, and DI exceptions from hooks retain their identity.
- Interrupted lazy initialization can retry with fresh arguments. Virtual proxies can defer to factories that own nonpublic constructors.
- External lookups include containers registered during ownership checks. Request mapping applies the selected conflict policy to recursive input and preserves caller-owned values during transformation.

Composer resolves `symfony/polyfill-php83` to 1.30 or later when the polyfill is installed. Earlier versions can emit a deprecation while loading on PHP 8.4 and newer.

The release workflow verifies the tag points to the commit that passed the checks before creating a GitHub release.

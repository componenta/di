# Componenta DI v5.0.7

[English version](https://github.com/componenta/di/blob/v5.0.7/docs/releases/v5.0.7.md)

Этот патч исправляет разрешение зависимостей и создание ленивых объектов в DI 5. Версия поддерживает PHP `^8.4` и публичный PHP API `v5.0.6`.

- Фабрики, делегаторы и подготовленные callable сохраняют выбранный объект и метод при автозагрузке. Ленивая фабрика HTTP-запросов кеширует проверенный сервис и может повторить получение после ошибки.
- Нормализация конфигурации и разрешение аргументов сохраняют ключи массивов, следующий индекс добавления и идентичность прикладных объектов. Изменение внешних ссылок больше не меняет уже принятую конфигурацию.
- Композиция атрибутов повторно проверяет объявления, которые стали доступны при автозагрузке. Метаданные пользовательских рефлекторов хранятся отдельно от кеша нативных планов.
- Инъекция свойств использует область объявления унаследованного приватного сеттера. Геттер может вернуть значение до инициализации поля, а исключения DI из хуков сохраняют идентичность.
- Прерванная ленивая инициализация при повторном обращении получает актуальные аргументы. Виртуальные прокси могут отложить вызов фабрики, которая создаёт объект с закрытым конструктором.
- Поиск во внешних контейнерах учитывает регистрации, сделанные во время проверки владельца. Преобразование HTTP-запросов учитывает выбранную политику конфликтов для рекурсивных данных и сохраняет исходные значения пользователя.

При установке `symfony/polyfill-php83` Composer выбирает версию 1.30 или новее. Предыдущие версии могут выдавать предупреждение об устаревании при загрузке на PHP 8.4 и новее.

Перед публикацией GitHub Release проверяет, что тег указывает на коммит, прошедший проверки.

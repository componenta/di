# Поведение и исключения

## Повторное использование значений

`get()` сохраняет результат разрешения собственной записи контейнера с учётом обработчиков результата под запрошенным идентификатором. Это может быть объект, число, строка, `null` или `false`. Для внешнего контейнера правила повторного использования определяет он сам; собственные сохранённые значения и обработчики результата не применяются к его ответам.

`make()` каждый раз обращается к собственному способу создания и требует объект в результате. Метод не применяет обработчики результата и не возвращает сохранённое значение из `get()`. При этом прикладная фабрика вправе самостоятельно возвращать один и тот же объект.

Сведения механизма отражения, подготовленные способы разрешения параметров и пути псевдонимов хранятся в памяти контейнера. Изменение привязок сбрасывает затронутые значения, не требуя пересоздания контейнера. Правила сборки и проверки одинаковы при разработке и эксплуатации.

## Исключения

Исключения библиотеки реализуют `Componenta\DI\Exception\ExceptionInterface`, расширяющий договорённости PSR-11 об исключениях контейнера.

| Исключение | Причина |
| --- | --- |
| `NotFoundException` | Запрошенная запись отсутствует. |
| `ResolutionException` | Не удалось создать объект либо разрешить зависимость. |
| `CircularDependencyException` | Обнаружена циклическая зависимость. |
| `ConcurrentResolutionException` | Разрешение конфликтует с другим активным выполнением. |
| `InvalidConfigurationException` | Недопустимая конфигурация или регистрация. |
| `AttributeCompositionException` | Несовместимое сочетание атрибутов. |
| `DelegatorException` | Ошибка при разрешении или вызове обработчика результата. |
| `MutationRetirementException` | Изменение уже применено, но освобождение заменённых значений завершилось ошибкой. |

Ошибки фабрик и конструкторов обрабатываются в соответствующей точке разрешения зависимостей; исходное исключение может сохраняться в `getPrevious()`. Когда управление уже передано явно вызванной функции или методу, исключение из его тела передаётся без изменения.

Регистрация, отклонённая до применения, сохраняет прежнюю привязку. Если после применения изменения возникла ошибка при освобождении заменённых значений, `MutationRetirementException` содержит затронутый `id` и упорядоченный массив причин `causes`. Повторять регистрацию автоматически нельзя. Независимо завершённые вложенные изменения не откатываются.

Подробнее об изменениях обработки ошибок см. [«Миграция определений»](../migrations/di6-definitions.md).

# Разрешение и вызов функций и методов

Перечисленные классы принадлежат пространству имён `Componenta\DI`. Контейнер предоставляет основные операции через `Container::call()` и `Container::resolve()`.

## Интерфейсы и реализации

| Тип | Открытые методы и свойства | Назначение |
| --- | --- | --- |
| `CallableResolverInterface` | `resolve(mixed $callable): callable` | Преобразование описания вызова в вызываемое значение без выполнения. |
| `CallableResolver` | `__construct(ContainerInterface $container)`; `resolve(mixed $callable): callable` | Поиск замыканий, функций, методов, служб и вызываемых объектов. |
| `CallableInvokerInterface` | `call(mixed $callable, array $params = []): mixed` | Вызов функции или метода с переданными аргументами; реализация может разрешать недостающие зависимости. |
| `CallableInvoker` | `call(mixed $callable, array $params = []): mixed` | Вызов без дополнительного разрешения зависимостей. |
| `CallableExecutorInterface` | Объединяет два предыдущих интерфейса | Общий договор на разрешение и выполнение вызовов. |
| `CallableExecutor` | `__construct(CallableResolverInterface $callableResolver, ParametersResolver $parameters)`; `resolve()`; `call()` | Разрешение параметров через контейнер и выполнение вызова. |
| `PreparedCallable` | `__construct(callable\|array $callable)`; `__invoke(mixed ...$arguments): mixed`; свойство `$callable` | Вызов с уже подготовленными аргументами без повторного внедрения зависимостей. |

## Поддерживаемые описания вызова

`CallableResolver` принимает `Closure`, имя функции, строку `Class::method`, массив `[$objectOrClass, 'method']`, идентификатор службы с вызываемым значением и объект с методом `__invoke()`. Для строковых значений точное совпадение с зарегистрированным идентификатором службы проверяется **раньше**, чем синтаксис функции или метода.

Методы экземпляров могут разрешаться через контейнер. Уже допустимые вызываемые значения PHP, переданные не строкой, сохраняют обычный приоритет. Методы через `__call()` получают аргументы по правилам PHP без анализа их параметров отражением. Некорректная форма вызова приводит к `InvalidCallableException`.

```php
$result = $container->call(
    [Controller::class, 'show'],
    ['id' => 10],
);

$callable = $container->resolve('controller.handle');
```

Метод `resolve()` только возвращает вызываемое значение. `call()` дополнительно разрешает отсутствующие типизированные аргументы и атрибуты параметров, включая простые объединения типов с единственным доступным кандидатом.

## Вызов с готовыми аргументами

`CallableInvoker` **не выполняет автоматическое внедрение зависимостей**. Он получает полный список аргументов и может передавать в PHP массив со ссылочными значениями. `PreparedCallable`, напротив, передаёт значения без сохранения ссылочной семантики и не подходит для ссылочных параметров.

Для магического метода, переданного массивом или строкой, `CallableInvoker` сохраняет порядок аргументов, имена и ссылки по правилам PHP. При проверке массива с квалифицированным методом предка PHP сообщает об устаревшем синтаксисе.

```php
use Componenta\DI\PreparedCallable;

$handler = static fn(int $id): int => $id * 2;
$prepared = new PreparedCallable($handler);
$result = $container->call($prepared, ['id' => 5]); // 10, без повторного разрешения
```

Для `PreparedCallable` значения параметров переменной длины необходимо раскрыть заранее. Именованные аргументы и значения по умолчанию следуют правилам PHP. Исключение из тела явно вызванной функции передаётся без изменения, а ошибки подготовки и неверные описания вызова относятся к исключениям библиотеки.
